## Требования

Python 3.10+. Моделирование не требует внешних библиотек: агенты, протоколы, механизмы распределения и переговоров запрограммированы явно, без МАС-фреймворков. Для построения графиков (`analyze.py` в ЛР2–ЛР4) нужен `matplotlib`.

## Быстрый старт

Каждая работа запускается из своей папки:

```bash
cd ЛР1
python run.py --mode both
```

Режимы демонстрации, параметры и команды для воспроизведения экспериментов описаны в `README.md` каждой папки. Эксперименты детерминированы: при одинаковом зерне результаты совпадают до такта (кроме замеров процессорного времени).
