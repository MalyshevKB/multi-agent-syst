# МАС координации складских роботов — ЛР3

Исходный код к ЛР3 «Проектирование механизма переговоров и разрешения конфликтов».
Отчёт — [ЛР3_Отчёт.md](ЛР3_Отчёт.md). Система — из ЛР1–ЛР2. Добавлены: арбитраж слотов зарядки по приоритету,
протокол переговоров об уступке слота, реестр репутации с санкциями, нечестные агенты, срочные заказы.

## Требования

Python 3.10+. Моделирование не требует внешних библиотек; для графиков (`analyze.py`) нужен `matplotlib`.

## Демонстрация

Сравнение политик FIFO / приоритет / переговоры / переговоры + репутация:

```bash
python run.py --policy all --seed 2
```

Зерно 2 выбрано для демонстрации потому, что на нём у станций образуются очереди из 2–3 роботов. При зерне 1 очередь не превышает одного робота, и приоритет совпадает с FIFO: переупорядочивать нечего.

То же, когда два робота лгут о заряде и не уступают слот:

```bash
python run.py --policy all --liars 2 --seed 2
```

Один вариант с картой склада каждые 50 тактов:

```bash
python run.py --policy negotiation --reputation --liars 2 --seed 2 --render 50
```

| Параметр | По умолчанию | Смысл |
|---|---|---|
| `--policy fifo\|priority\|negotiation\|all` | `all` | политика распределения слотов зарядки |
| `--reputation` | выкл. | проверка заявок, репутация и санкции (для `negotiation`) |
| `--liars k` | 0 | число роботов, занижающих заявленный заряд |
| `--charge-rate r` | 3 | скорость зарядки (меньше — острее дефицит) |
| `--stations 1\|2` | 2 | число работающих зарядных станций |
| `--robots N`, `--orders N`, `--rate p`, `--seed S` | 8, 100, 0.1, 1 | сценарий |
| `--mode` | `auction` | механизм распределения задач из ЛР2 |
| `--render N`, `--trace file.jsonl`, `--json` | — | визуализация, трасса, JSON |

Параметры механизмов (веса приоритета, пороги уступки, срок санкций и т. д.) — в `warehouse_mas/config.py`.

## Эксперименты

Серии E1–E4 (420 прогонов) → `results/E*.csv`:

```bash
python experiments.py
```

Сводные таблицы `results/summary.md` и графики `figures/*.png`:

```bash
python analyze.py
```

Проверка на длинном горизонте (150 заказов, 2 лжеца; отчёт, п. 4.2):

```bash
python long_horizon.py
```

## Где что реализовано

| Файл | Содержание |
|---|---|
| `agents/charging.py` | станция-арбитр: политики `fifo` / `priority` / `negotiation`, проверка заявок, отзыв слота |
| `agents/reputation.py` | реестр репутации, кредитов взаимности и санкций |
| `agents/robot.py` | заявка на зарядку (честная / ложная), ответ на предложение уступить слот |
| `agents/order_manager.py` | экспресс-заказы со сроками |
| `agents/dispatcher.py` | приоритет экспресс-задач в аукционе (EDF) |
