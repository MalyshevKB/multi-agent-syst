# МАС координации складских роботов — ЛР2

Исходный код к ЛР2 «Исследование механизмов распределения задач и координации».
Отчёт — [ЛР2_Отчёт.md](ЛР2_Отчёт.md). Система — из ЛР1, дополнена механизмами `hungarian`, `auction` и `delegation`.

## Требования

Python 3.10+. Моделирование не требует внешних библиотек; для графиков (`analyze.py`) нужен `matplotlib`.

## Демонстрация

Сравнение всех пяти механизмов на одном потоке заказов:

```bash
python run.py --mode all
```

Один механизм с картой склада каждые 20 тактов:

```bash
python run.py --mode auction --render 20
```

| Параметр | По умолчанию | Смысл |
|---|---|---|
| `--mode central\|hungarian\|cnp\|auction\|delegation\|all` | `central` | механизм распределения задач |
| `--robots N` | 6 | число роботов (до 12) |
| `--orders N` | 40 | число заказов |
| `--rate p` | 0.12 | вероятность появления заказа на такте |
| `--seed S` | 1 | зерно генератора |
| `--charger-slots K` | 1 | слотов на каждой из двух зарядных станций |
| `--fail robot_i:T` | — | отказ робота на такте T |
| `--render N` | 0 | печатать карту каждые N тактов |
| `--trace file.jsonl` | — | трасса всех сообщений |
| `--json` | — | метрики в JSON |

Параметры механизмов (период аукциона, порог делегирования, размер матрицы назначений и т. д.) — в `warehouse_mas/config.py`.

## Эксперименты

Все серии E1–E4 (680 прогонов) → `results/E*.csv`:

```bash
python experiments.py
```

Сводные таблицы `results/summary.md` и графики `figures/*.png`:

```bash
python analyze.py
```

## Механизмы распределения (`agents/dispatcher.py`, `agents/robot.py`)

| Режим | Суть |
|---|---|
| `central` | диспетчер назначает задачи по своей модели состояния роботов (роботы шлют статусы), жадно, FIFO |
| `hungarian` | оптимальное централизованное назначение Венгерским алгоритмом (`warehouse_mas/hungarian.py`) |
| `cnp` | контрактная сеть: тендер на каждую задачу, CFP → PROPOSE/REFUSE → ACCEPT/REJECT |
| `auction` | пакетный закрытый аукцион первой цены: лот до 10 задач раз в 5 тактов, жадное определение победителей |
| `delegation` | распределённое делегирование: задача идёт по кольцу роботов, пока кто-то не возьмёт её по порогу стоимости |
