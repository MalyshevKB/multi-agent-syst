# МАС координации складских роботов

Исходный код к лабораторным работам по курсу «Теория многоагентных систем».
Отчёт по ЛР1 — [ЛР1_Отчёт.md](ЛР1_Отчёт.md).

## Требования

Python 3.10+, внешних зависимостей нет.

## Запуск

```bash
python run.py --mode both
```

Основные параметры:

| Параметр | По умолчанию | Смысл |
|---|---|---|
| `--mode central\|cnp\|both` | `central` | механизм распределения задач (`both` — сравнение на одном потоке заказов) |
| `--robots N` | 6 | число роботов (до 12) |
| `--orders N` | 40 | число заказов |
| `--rate p` | 0.12 | вероятность появления заказа на такте |
| `--seed S` | 1 | зерно генератора (воспроизводимость) |
| `--charger-slots K` | 1 | слотов на каждой из двух зарядных станций |
| `--battery B` | 120 | ёмкость батареи |
| `--fail robot_i:T` | — | отказ робота на такте T (можно несколько раз) |
| `--render N` | 0 | печатать карту склада каждые N тактов |
| `--trace file.jsonl` | — | трасса всех сообщений |
| `--json` | — | метрики в JSON |

Примеры:

```bash
python run.py --mode cnp --render 20
```

```bash
python run.py --mode both --fail robot_2:150
```

```bash
python run.py --mode central --trace trace.jsonl
```

Обозначения на карте: `#` стеллаж, `P` станция упаковки, `C` слот зарядки, `w` место ожидания зарядки,
цифра — робот, `X` — отказавший/разряженный робот. Под картой — состояние роботов:
`номер:состояние[заряд]текущая_задача+длина_очереди`.

## Структура

```
warehouse_mas/
  config.py          параметры модели
  messages.py        перформативы FIPA-ACL, сообщение, шина доставки и подсчёт стоимости
  environment.py     карта склада, односторонние проходы, поиск путей
  simulation.py      сборка МАС, тактовый цикл, отказы, метрики
  render.py          текстовая визуализация
  agents/
    base.py          базовый агент
    order_manager.py менеджер заказов
    dispatcher.py    диспетчер (central / cnp)
    robot.py         робот (гибридная архитектура)
    traffic.py       регулировщик движения
    charging.py      зарядные станции
    monitor.py       наблюдатель (трасса, heartbeat)
run.py               CLI-демонстрация
```
